# Café Andino: la junta directiva

Juego multijugador sobre Responsabilidad Social Empresarial (RSE) para una exposición universitaria.

- El presentador abre la página y crea una sala.
- Los estudiantes entran desde el celular con el código de la sala o el QR, sin crear cuenta.

Todo el juego está en `index.html` (HTML, CSS y JavaScript, sin compilación).
